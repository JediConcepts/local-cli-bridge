3D Maps Fly-Through

The same London and Monaco tours as the tiles demo, but rendered by Google's own Photorealistic 3D Maps web component (Map3DElement) instead of raw 3D Tiles in Three.js — Google's renderer brings its own sky, atmosphere and camera choreography.

Needs a Google Maps Platform API key with the Maps JavaScript API enabled (how to get one). The key is kept in your browser's localStorage only.
