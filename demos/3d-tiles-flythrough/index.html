3D Tiles Fly-Through

Streams Google's Photorealistic 3D Tiles into a Three.js scene and flies you along the Thames in London or the Grand Prix line in Monaco.

You need a Google Maps Platform API key with the Map Tiles API enabled (how to get one). The key is kept in your browser's localStorage only.
