## Attribution policy (non-negotiable)

Never attach AI attribution to anything in this repository:

- No `Co-Authored-By`, `Generated with`, session-link, or any other AI-credit
  trailers in commit messages, PR titles, or PR bodies.
- Commits must carry the repository owner's git identity
  (`Jedi Concepts <jamie@jediconcepts.com>`). The SessionStart hook in
  `.claude/settings.json` configures this automatically — verify
  `git config user.email` before the first commit of a session and never
  commit as an AI identity.
- No AI credits in code comments, docs, or release notes.
